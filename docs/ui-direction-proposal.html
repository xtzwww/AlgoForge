AlgoForge 界面改版 三套风格方向 · 学生端 + 教师端

同一个系统，三种性格。

下面三套方案用的是完全相同的页面结构和功能——同样的侧边栏、同样的题面/代码/反馈三栏、 同样的教师看板。我只换了颜色、间距、圆角和字体。所以你在挑的是一件纯粹的审美和气质的事， 不用担心"选了 A 是不是功能就少了"。

01
为什么先挑风格，不先挑页面

风格是地基。地基定了，后面十几个页面的每一处细节才有唯一答案；地基不定，每页都会长成另一个样子。

02
怎么用这一页

上面三个按钮切换方向。每个方向里有两张"效果图"：学生做题的页面，和老师看班级的页面。滚到最后有横向对比表。

03
你只需要回答一个问题

哪一套让你觉得"这就是我想让人看到的软件"。剩下所有的页面、按钮、空状态，我按这个方向铺开。

一眼看三者

左边是深色高密度的"专业工具"，中间是浅色宽松的"教学讲义"，右边是深色极简的"一次一件事"。三者最大的差别不是颜色，是一屏放多少信息。

横向对比

按"这套界面要服务什么"来比，不按好看程度比——好看是主观的，能不能用是客观的。

我的建议

选「聚焦镜」，教师端把密度调到中档。

理由只有一条：你这套系统真正跟别人不一样的地方，是把 AI 的诊断拆成三层、一层一层放给学生。 这是教学设计上的创新点，也是答辩时最该被看见的东西。而"仪器台"和"讲义纸"都把反馈挤成了屏幕边上的一个小栏， 等于把最亮的牌扣在手里。聚焦镜让反馈占据整屏——学生的注意力别无选择。

如果你更在意"老师端要显得专业" 那就选仪器台。它一屏能放下班级所有数据，老师不用翻页；代价是它看起来像很多同类工具，缺一点自己的脸。
如果你更在意"答辩时投影要清楚" 那就选讲义纸。浅底投影仪上最清楚，也最不像"学生自己写的小工具"。代价是要接受它和深色代码编辑器拼在一起时有一点反差。
三个都不满意也完全可以 直接告诉我哪里不对——是颜色、是松紧、是太冷还是太素。风格可以杂交：比如取聚焦镜的松，配仪器台的青。
你定一个方向，我接着做：
把这个方向铺到全部页面（练习 / 我的作业 / 题库 / 错题本 / 画像 / 复习 / 学情看板 / 班级管理），补上按钮、输入框、弹窗、加载和空状态，再给一份配色和字号清单。

说明：本页所有界面均为静态示意图，不是可以真的操作的软件。里面出现的班级名、学生姓名、分数、 报错信息都是编造的示例数据，用来说明"东西多了之后长什么样"。真实开发时这套样式会落到项目现有的 Vue 组件里， 不改变任何功能。
