# AlgoForge 界面设计方案 v2 ——「曜石灰」暗色体系

> 配套原型：`docs/ui-prototype-2026-09-25.html`（双击打开，10 个页面可点）
> 适用范围：学生端 6 页 + 教师端 2 页 + 登录/注册
> 技术约束：`AGENTS.md` §一 —— Vue 3 + TypeScript + Tailwind v4（CSS-first）+ shadcn-vue，
> 不改框架、不改组件库。本方案只动 `tokens.css` / `tokens.ts` / 各视图样式。

---

## 0. 一句话

**用一套克制的暗色中性体系，把「编辑器」还给屏幕中央，把「颜色」还给结果。**

上一版（霓虹深空）的问题是：辉光、网格、彩色边框在每一个面板上都出现，
装饰和语义抢同一块注意力——学生看 WA 红和看侧边栏蓝紫用的是同一种视觉权重。
这一版把颜色从「装饰」里收回来，只让它在三种地方出现：**可交互、当前位置、判定结果**。

## 1. 设计目标（按优先级）

| # | 目标 | 可验证的方式 |
|---|---|---|
| 1 | **练习页第一屏就能写代码**，不需要任何点击 | 打开练习页，编辑器可见区域 ≥ 视口 55% |
| 2 | 判定结果一眼可见，且颜色不与其他元素冲突 | 全站彩色元素 ≤ 12 处/屏，其中语义色只出现在结果区 |
| 3 | 反馈分层真的被使用，而不是被跳过 | 分层反馈第 1 层默认展开，2/3 层需显式点击 |
| 4 | 教师端一屏看完「谁要管、全班弱在哪」 | 看板首屏含 KPI + 需要关注 + 错因分布 |
| 5 | 长时间使用不疲劳（这是毕设演示要跑 1 小时的场景） | 无大面积高饱和填充；正文对比度 ≥ 7:1 |
| 6 | 键盘可达、屏幕阅读器可读 | 见 §7 无障碍清单 |

## 2. 用户习惯依据（每一条都对应一个具体决定）

| 用户已有的习惯 | 来源 | 本方案的做法 |
|---|---|---|
| 编辑器是最大的一块，代码在左/中，题面在旁 | VS Code、LeetCode、PTA | 练习页三区：题面 340px（可折叠）· 编辑器 flex-1 · 底部面板 242px |
| 运行结果在下方面板，不在右侧弹窗 | VS Code 终端、DevTools | 底部面板固定页签：输出 / 用例 / AI 诊断 / 调试 / 学习过程 |
| 提交是主按钮，运行是次按钮，且都有快捷键 | LeetCode、Codeforces | 主按钮实心蓝紫（提交），次按钮描边（运行），`Ctrl+Enter` / `Ctrl+Shift+Enter` |
| AC 绿、WA 红、TLE 黄、CE 紫 | 全体 OJ | **判定色一字不改**。这是唯一「不能创新」的地方，改了就是反习惯 |
| 左侧导航 = 我在哪 | 所有桌面工具 | 侧边栏分组：学习 / 教学；当前页用左侧 3px 竖条 + 向右淡出渐变 |
| 表格里的数字要能竖着读 | 成绩单、排行榜 | 全站 `font-variant-numeric: tabular-nums` + 数字列右对齐等宽 |
| 空页面要给下一步动作 | 成熟产品的 Empty State | 空状态必须带一个主按钮（去题库 / 去练习 / 新建班级） |
| 教师先看异常，再看统计 | 教务系统、监控看板 | 看板顺序：KPI → 需要关注 → 错因分布 → 知识点 → 清单 → 存疑 |
| 反馈一次给太多会直接跳到答案 | 支架式教学（项目自身理论） | 分层反馈三层释放，第 3 层可「重新自己想」收起 |

> **一条刻意的反习惯**：判定色沿用 OJ（绿=通过），但**不用红色表示"上涨/好"**。
> 本项目没有金融语义，不适用红涨绿跌；全站红 = 出错/危险，绿 = 通过/成功。

## 3. 信息架构

```
智能学情反馈
├─ 学习（学生端 · 默认）
│   ├─ 练习          /practice        编辑器三区，自由运行 / 题库题目共用
│   ├─ 我的作业      /assignments     班级 → 作业 → 逐题状态
│   ├─ 题库          /problems        搜索 + 难度/知识点/状态筛选
│   ├─ 错题本        /mistakes        错因 × 知识点筛选，卡片展开看三层反馈
│   ├─ 能力画像      /profile         KPI + 雷达图 + 知识点表
│   └─ 复习          /plan            SM-2 到期列表 + 0–5 打分
├─ 教学（教师端）
│   ├─ 学情看板      /teacher         KPI → 关注 → 分布 → 掌握 → 清单 → 存疑 → 作业 → 账号
│   └─ 班级管理      /teacher/classes 建班 / 导入名单 / 发作业
└─ （隐藏路由）登录 /login、注册 /register
```

**三条 IA 决策**

1. **练习页 = 首页**。产品的核心动作是写代码，不是看数据；打开即练习。
2. **班级管理与学情看板平级**，不是看板的下钻。教师是「先建班才有数据」，
   把它做成下钻等于让新教师先看到一个空的看板。
3. **登录/注册不进侧边栏**（沿用现有 `meta.hidden`）。已登录时侧边栏里挂个
   「登录」是在邀请用户开第二个账号。

## 4. 设计系统

### 4.1 表面：四级明度阶梯

层级只靠**明度 + 1px 分隔线**表达，不靠彩色边框、不靠阴影堆叠。

| Token | 值 | 用在 |
|---|---|---|
| `--canvas` | `#0B0D12` | 应用底色。仅一处极淡顶部渐晕（`rgba(110,139,255,.10)`）给方向感 |
| `--surface` | `#13161D` | 常驻面板：侧边栏、卡片、表格容器、编辑器 |
| `--elevated` | `#1A1E27` | 悬浮态、表头、输入框、chip、折叠面板体 |
| `--overlay` | `#232833` | 下拉、弹窗、抽屉、Toast |
| `--border` | `rgba(255,255,255,.09)` | 默认分隔线 |
| `--border-strong` | `rgba(255,255,255,.18)` | 悬浮/聚焦时的分隔线 |

> 玻璃拟态**收敛**：只有浮层（下拉 / 弹窗 / Toast / 顶栏）用毛玻璃，
> 常驻面板一律实色。上一版侧边栏半透明+模糊，网格线会从文字后面透出来，
> 在 14px 中文上直接变成噪点。

### 4.2 文字：三级 + 反色（对比度均为实测值）

| Token | 值 | on surface | on elevated | 用途 |
|---|---|---|---|---|
| `--tx1` | `#E8EAF0` | **15.05:1** | — | 标题、正文、代码 |
| `--tx2` | `#A0A6B8` | **7.45:1** | 6.86:1 | 次要说明、表格正文 |
| `--tx3` | `#868EA3` | **5.53:1** | 5.09:1 | 标签、脚注、元信息 |
| `--tx-inv` | `#0B0D12` | — | — | 压在 accent/success/warning 填充上的字 |

`--tx3` 特意提到 **5.53:1**（上一版 `#6d7c9e` 只有 3.66:1）：
它是全站最低档文字，也是唯一一档会大量出现在小字号上的颜色，**必须过 AA**。
反色字是**近黑不是白**：accent `#6E8BFF` 是亮蓝，白字只有 3.09:1（不达标），
`#0B0D12` 是 **6.29:1**。任何残留的 `color:#fff` 按钮都是对比度 bug。

### 4.3 主色：单一蓝紫，只做三件事

| Token | 值 | 用途 |
|---|---|---|
| `--accent` | `#6E8BFF` | 主按钮填充、当前导航竖条、进度条、聚焦环 |
| `--accent-hover` | `#8AA1FF` | 悬浮 |
| `--accent-active` | `#5B76F0` | 按下 |
| `--accent-subtle` | `#1C2440` | 选中态底色（chip、当前导航渐变起点） |
| `--accent-alt` | `#A78BFA` | **仅**渐变右端与雷达图描边，不单独当主色 |

accent 允许出现的三种语义：**可交互 / 当前位置 / 进行中**。
不允许用它做装饰性描边、不允许把卡片边框染蓝——那是上一版最贵的视觉债。

### 4.4 语义色与判定色

| 语义 | 值 | 同时承担 |
|---|---|---|
| success | `#3DDC97` | AC |
| warning | `#FFB454` | TLE |
| danger | `#FF6B7A` | WA |
| info | `#4CC9F0` | MLE |
| purple | `#A78BFA` | CE |
| — | `#FF9455` | RE |
| — | `#A0A6B8` | UNKNOWN |

**判定色不允许被主题化、不允许被重排**。学生是从别的 OJ 迁移过来的，
绿=通过这条肌肉记忆比任何一致性收益都值钱。

### 4.5 尺度

| 项 | 值 | 说明 |
|---|---|---|
| 侧边栏 | 240px（折叠 64px，<1100px 抽屉） | 中文标签 + 图标，240 是「不换行」的下限 |
| 顶栏 | 52px | 面包屑 + 用户 + 全局动作 |
| 题面列 | 340px（可折叠到 44px） | 折叠后编辑器吃满宽度 |
| 底部面板 | 242px | 5 个页签，够放 3 行用例 |
| 版心 | 1160px | 读类型页面（题库/错题本/画像/复习/看板） |
| 圆角 | 10 / 14 / 18px | 10 是最小可辨识的「刻意」；按钮/输入 10，卡片 14，大容器 18 |
| 间距 | 4px 基准，常用 8/12/14/16/22 | 卡片间距 14，页边距 24 |
| 动效 | 120 / 180 / 280ms，`cubic-bezier(.4,0,.2,1)` | 上限 280ms：桌面工具不该「慢」 |

### 4.6 字体

- 正文：`-apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei'`
- 数字/代码：`ui-monospace, 'Cascadia Mono', 'SF Mono', Consolas, 'Liberation Mono'`
- 字阶：22/650（页标题）· 16/600（练习页题目标题）· 14/600（卡片标题）·
  14/400（正文）· 13/400（次要）· 12/400（标签脚注）
- 行高 1.6；**全站 `tabular-nums`**（这一条是最高性价比的改动）

## 5. 组件规范（只列与现网有差异的）

| 组件 | 规范 | 与现网差异 |
|---|---|---|
| 按钮 | 高 36px（小 28px），圆角 10；主按钮实心 accent + 反色字，次按钮 `elevated` 底 + 描边，文字按钮透明底 | 去掉主按钮的辉光，改用 `:active` 下移 1px |
| 徽章 | 高 22px，圆角 7，**语义色只做 10–16% 底 + 28% 边** | 底色比上一版更淡，避免整行被染色 |
| 卡片 | 圆角 14，`surface` 底 + 1px 边，**无阴影** | 去掉 `box-shadow`；层级靠底色不靠投影 |
| 表格 | 表头 `elevated` + 12px 小字；数字列右对齐等宽；行悬浮 `elevated` | 去掉斑马纹，改用 1px 分隔线 |
| 页签 | 下边框 2px accent，无背景块 | 与现网一致，保留 |
| 下拉/弹窗 | `overlay` 底 + 毛玻璃 + `--sh-3` | 毛玻璃**只**在这里用 |
| 进度条 | 高 6px，圆角 999；`.ok/.warn/.bad` 三档 | 新增 `bad` 档对应掌握度最弱档 |
| Notice | 琥珀底 8% + 22% 边，带图标 | 用于「需要注意但不阻断」（语言不可用、打分规则） |
| Toast | 右下角，`overlay` 底，2400ms 自动消失 | 与现网一致 |
| 空状态 | 图标 + 标题 + 解释 + **一个主按钮** | 强制带行动入口 |
| 骨架屏 | 加载 >300ms 才显示 | 避免快接口的闪烁 |
| **分层反馈 Ladder** | 见下节 | 本产品最核心的组件 |

### 5.1 分层反馈 Ladder（核心组件）

```
┌ ① 错在哪 ───────────────────────────── 已展开 ┐   ← 默认展开
│ 指出实际错因（学生能读的中文）                  │
│ [整数溢出] [数据类型]                          │
│ [还是不会，给点提示 →]                         │
└──────────────────────────────────────────────┘
┌ ② 提示 ──────────────────── 虚线边框 · 锁定 ──┐   ← 点击后解锁
│ 只给方向，不给答案                             │
│ [还是不会，直接看怎么改 →]                     │
└──────────────────────────────────────────────┘
┌ ③ 怎么改 ────────────────── 虚线边框 · 锁定 ──┐
│ 完整修改建议 + 代码块                          │
│ [来道同类题练手]  [重新自己想（收起 2、3 层）] │
└──────────────────────────────────────────────┘
```

- 锁定层用**虚线边框 + 灰阶序号**，不用遮罩：让学生知道「下面还有」但不给内容。
- 「重新自己想」是产品要求（README §2.1），必须能回到只看第 1 层。
- 释放进度**不持久化**（沿用现有约定）：离开页面回来重新从第 1 层开始。
- 历史联动提示（「这个错因你犯过 4 次」）放在 Ladder **上方**，不占层级内部。

## 6. 页面规范

### 6.1 练习 `/practice`（首页）

```
┌ 题目标题 + 题库徽章 + 判定徽章 ───── [语言▾][运行][提交] ┐
├──────────────┬──────────────────────────────────────────┤
│ 题面 340px   │ 编辑器（flex-1，最小 55% 视口高）          │
│ 描述/输入/   │  main.cpp · 行号栏可打断点                 │
│ 输出/样例    ├──────────────────────────────────────────┤
│ [收起 ‹]     │ 输出│用例 3/10│AI 诊断│调试│学习过程      │
└──────────────┴──────────────────────────────────────────┘
```

- 题面折叠后列宽 44px，标签竖排「题面」，编辑器吃满宽度。
- 底部面板 5 页签；**AI 诊断**页签内嵌 Ladder；进入 WA 后自动切到该页签。
- 快捷键：`Ctrl+Enter` 运行、`Ctrl+Shift+Enter` 提交，写在按钮的 tooltip 与 `kbd` 里。

### 6.2 我的作业 `/assignments`

左：班级列表（260px，当前班级用 `accent-subtle` 底）；右：作业卡片流。
每张卡：标题 · 截止+剩余时间+辅助强度 · 进度条 · **逐题状态点阵**（22px 方格，AC 绿/未过红/未做灰）。
主按钮是「继续做第 N 题」——直接跳到第一个未通过的题。

### 6.3 题库 `/problems`

搜索框（flex-1）+ 难度 chip（全部/入门/中等/困难）+ 知识点下拉 + 状态下拉。
表格列：题号 · 标题 · 难度 · 知识点 · 通过率 · 状态。默认题号升序。
筛选在**客户端取交集**（沿用现有实现），并在右上角注明。

### 6.4 错题本 `/mistakes`

错因下拉（选项来自列表里真实出现过的错因，按中文排序）+ 知识点下拉。
卡片：题号+标题 · 最近时间+语言 · 判定徽章+错因标签；展开后是内嵌 Ladder + 「再做一次 / 加入复习计划」+ 历史出现次数。

### 6.5 能力画像 `/profile`

KPI 四卡（总正确率 / 知识点数 / 总提交数 / 最需补强）+ 雷达图 + 图例 + 详细统计表。
- 雷达图**数据不足时不画**（沿用现有 `MIN_SUBMISSIONS_FOR_RADAR` 判定），
  改为「还差 N 次解锁」的说明卡 —— 误导性的多边形比没有多边形更糟。
- 表格按正确率**升序**：最需要补的排最上面，并在表头下方写明排序理由。

### 6.6 复习 `/plan`

顶部 Notice 说明「打分只影响下次复习时间，不影响成绩」。
每条：题号+标题 · 上次复习/间隔/难度系数 · 0–5 打分按钮组 · 「下次：N 天后」实时反馈。

### 6.7 学情看板 `/teacher`

顺序固定：**KPI（提交数/平均正确率/需要关注/待复核）→ 需要关注 → 错因分布 → 知识点掌握 → 学生清单 → 存疑提交 → 作业 → AI 使用记录 → 成绩单 → 账号**。
- 「需要关注」三档图标色不同（红=连续未过、蓝=长期无提交、紫=全班共性错因）。
- 存疑提交的「确认 / 驳回」：驳回 = 判为误报，退出队列但**保留全部特征数据**，
  按钮旁必须写明这句话（这是教师最可能误操作的地方）。
- 未登录/非教师：整页替换为登录卡或「此账号不是教师账号」，不做半屏骨架。

### 6.8 班级管理 `/teacher/classes`

左：新建班级表单（名称/课程/学期）；右：班级卡片（含邀请码）+ 批量导入名单（粘贴两列 + 解析）。

### 6.9 登录 / 注册

独立页（不共用一张卡的两个模式）。380px 居中卡，品牌头 + 表单 + 主按钮占满宽。
底部提供「以游客身份继续」——未登录也能练习，这是现有后端的真实行为，界面必须说出来。

## 7. 交互与无障碍清单

**键盘**

| 键 | 行为 |
|---|---|
| `Ctrl/Cmd + Enter` | 运行（公开样例，不记成绩） |
| `Ctrl/Cmd + Shift + Enter` | 提交（全部用例，记成绩） |
| `Esc` | 关闭抽屉 / 弹窗 / Toast |
| `Tab` / `Shift+Tab` | 焦点顺序：工具栏 → 编辑器 → 底部页签 → 面板内容 |
| 底部页签 | `role="tablist"`，左右方向键切换 |

**无障碍**

- 全部 ≥12px 文字对比度 ≥ 4.5:1（实测见 §4.2）；装饰性图标除外。
- 焦点环：`:focus-visible { outline: 2px solid accent; outline-offset: 2px }`，
  **不能删**——玻璃面板上的 1px outline 会跟面板自身边框打架。
- 图标按钮必须有 `aria-label`；纯装饰 SVG 加 `aria-hidden="true"`。
- 雷达图加 `role="img"` + `aria-label`（六项数值）；进度条加 `role="img"` + 百分比。
- `prefers-reduced-motion: reduce` 下关闭全部 transition（原型已实现）。
- 状态不能只靠颜色：判定徽章同时有文字（AC/WA/TLE），错题卡同时有文案。

**响应式**

| 断点 | 行为 |
|---|---|
| ≥ 1280px | 侧边栏展开（240px） |
| 1024–1280px | 侧边栏折叠为图标（64px），标签进 tooltip |
| < 1024px | 侧边栏变抽屉，**起点在顶栏下方**（否则遮罩会盖住汉堡按钮） |
| < 1100px | 练习页题面列隐藏，改为页签/弹层 |

## 9. 明确不做的事

- **不做亮色主题**：毕设演示场景是教室/答辩投影，暗色更稳；双主题会让
  `tokens.css` 的维护成本翻倍而收益不确定。
- **不换组件库**：shadcn-vue 是模板复制模式，不引入新依赖。
- **不动 Monaco 主题的接口**：`monaco-theme.ts` 读的是同一批 CSS 变量，换值即生效。
- **不改判定色语义**：详见 §4.4。
