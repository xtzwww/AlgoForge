题面

入门
数组模拟 时限 1s · 内存 256M

输入两个整数 a 和 b，输出它们的和。

输入格式

一行，两个以空格分隔的整数 a、b。

输出格式

一行，一个整数，表示 a + b 的结果。

样例

输入2 3
输出5
