# 0-1 背包

## 什么时候会用到

在**容量有限**的前提下，从一堆物品里选一部分，使总价值最大（或代价最小）。
每个物品**只能选一次**——这就是"0-1"的含义。若每个物品可以选多次，
那是完全背包，转移方程不同。

## 要点

### 状态定义

`dp[i][j]` = 只考虑前 `i` 个物品、背包容量为 `j` 时能获得的最大价值。

转移只有两种选择，且必须**都考虑到**：

```
dp[i][j] = max(
    dp[i-1][j],                                  // 不拿第 i 个
    dp[i-1][j - w[i]] + v[i]   (若 j >= w[i])     // 拿第 i 个
)
```

漏掉"不拿"那一支，是这一题最常见的错误——表现是答案偏小，
因为程序被迫每次都拿。

对应错因标签：`missing_case`。

### 边界

- `dp[0][j] = 0`：没有物品时价值为 0。
- `dp[i][0] = 0`：容量为 0 时价值为 0。
- **容量装不下某个物品时，只能不拿**——这个判断不能省，
  否则会访问 `j - w[i] < 0` 的非法下标。

对应错因标签：`off_by_one`、`boundary_condition`。

### 一维数组优化：容量必须倒序遍历

把二维压成一维后：

```
for (int i = 0; i < n; i++)
    for (int j = capacity; j >= w[i]; j--)      // 注意：从大到小
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
```

**为什么必须倒序**：正序遍历时，`dp[j - w[i]]` 可能已经是**本轮更新过**的值，
等于同一个物品被拿了多次——0-1 背包就退化成了完全背包，答案偏大。

这是背包问题最经典的坑，**必须理解而不是背**：倒序保证每个物品只用一次。

### 初值

- 求"最大价值"：`dp` 全 0 即可（不装任何东西价值为 0）。
- 若题目要求"恰好装满"：`dp[0] = 0`，其余设为负无穷（表示不可达）。

两者结果不同，看清题意。

对应错因标签：`uninitialized_state`。

## 常见错误

| 标签 | 表现 |
|---|---|
| `missing_case` | 漏掉"不拿"的分支，答案偏小 |
| `off_by_one` | 容量循环边界写成 `> w[i]`，或下标减错 |
| `uninitialized_state` | 一维优化时正序遍历，物品被重复使用 |
| `boundary_condition` | 容量不足时未判断，访问非法下标 |

## 自检清单

- 转移里"拿"和"不拿"两支都写了吗？
- 容量装不下当前物品时怎么处理？
- 若用一维数组：内层循环是**倒序**吗？
- 题目要求"恰好装满"还是"不超过容量"？初值对应改了吗？
- 物品数为 0、容量为 0 时输出对吗？
