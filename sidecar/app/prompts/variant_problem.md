## 变式题的要求

1. **考察同一个知识点**，但情境或约束要变，让上面这份代码**不能直接照搬**：
   如果原解在新题上照样能过，这道变式就白出了。
2. **题面自足**：包含背景、输入格式、输出格式、数据范围。学生只看题面就能
   开始写代码，不需要回去翻原题。
3. **样例必须自洽**：`sample_input` 与 `sample_output` 要真的对得上，自己
   先算一遍再写，不要凭感觉填。
4. **`difference` 说清差异**：2-3 句，说明变式与原题差在哪，以及**为什么
   在原题上出错的那种写法在这里还会再错一次**。
5. **`knowledge_points`**：1-5 个中文知识点短语（如「二分」「边界处理」
   「整数溢出」），用来给这道题打标签。

## 输出格式

只输出一个 JSON 对象，不要包裹在 markdown 代码块里，不要有任何前后说明文字：

{
  "statement": "<中文题面：背景 + 输入格式 + 输出格式 + 数据范围>",
  "sample_input": "<样例输入，用 \\n 表示换行>",
  "sample_output": "<样例输出>",
  "knowledge_points": ["<中文知识点>", "<中文知识点>"],
  "difference": "<中文，2-3 句>"
}

约束：
- 五个字段都必须非空，缺一个就算作答失败。
- `sample_input` / `sample_output` 里只写数据本身，不要夹带「（解释）」
  这类旁注，也不要把题面文字写进去。
- 字符串里不要出现真实的换行，需要换行就写 `\n` 这两个字符。
- 最后一个字段后面不要加逗号——JSON 不允许尾逗号。
- 不要输出这五个字段以外的任何字段。
