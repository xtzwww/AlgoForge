# ------------------------------------------------------------ RAG（阶段 8）
# AGENTS.md §二.2 把向量库锁定为 Milvus，对应的客户端是 pymilvus。
#
# 它是**可选**依赖，但列在这里：app/rag/ 的索引器（indexer.py）与检索器
# （retriever.py）都已实现，缺了 pymilvus 的话部署环境里的 RAG 永远不会生效
# ——而且**不会报错**，检索只是静静地降级成「没有上下文」（见 retriever.py
# 的降级设计）。那种沉默正是它该被显式列出来的理由。
# 本地开发若暂时不需要 RAG，可以不装：代码对它是懒导入，缺了照样跑。
#
# ⚠️ 本机实测的坑：Milvus 客户端会继承 HTTP(S)_PROXY。若本机设了代理而 Milvus
# 跑在 localhost，握手会以 `HTTP proxy returned response code 502` 失败，
# 看起来像「Milvus 没起」。跑 RAG 之前先清掉代理变量。
pymilvus>=2.4.0

#
# 故意**不**列进依赖：它会带进 faiss-cpu 与 pyarrow（上百 MB），而打包版
